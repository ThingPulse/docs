[Lade](https://code.visualstudio.com/) die offizielle Version von Microsoft Visual Studio Code herunter und installiere sie. PlatformIO IDE baut darauf auf.

1. Öffne die Erweiterungsverwaltung in VS Code.
2. Suche nach der offiziellen Erweiterung PlatformIO IDE.
3. Installiere PlatformIO IDE.

![Erweiterungsverwaltung von VS Code und Installation von PlatformIO IDE](../img/how-tos/platformio-install.png)

Sieh dir die [PlatformIO-Kurzanleitung](https://docs.platformio.org/page/ide/vscode.html#quick-start) an (sehr empfohlen).
