Mit der integrierten Entwicklungsumgebung Arduino IDE programmierst du den ESP8266. Eine IDE ist mehr als ein Texteditor: Sie unterstützt dich bei verschiedenen Aufgaben während der Entwicklung.

Rufe zur Installation https://www.arduino.cc/en/Main/Software auf und lade die neueste Version für dein Betriebssystem herunter:

- Unter macOS kannst du eine ZIP-Datei herunterladen und entpacken. Verschiebe die entpackte Anwendung „Arduino“ in den Ordner „Programme“.
- Unter Windows kannst du zwischen einem Installationsprogramm und einer ZIP-Datei wählen. Ohne Administratorrechte ist die ZIP-Datei möglicherweise die bessere Wahl. Das Installationsprogramm kann dagegen die Bibliotheken an den richtigen Stellen ablegen.

Damit hast du eine Arduino IDE mit allem, was du zum Programmieren der üblichen Arduino-ATmega-Chips benötigst. Wir möchten jedoch Code für den ESP8266 schreiben und kompilieren.
